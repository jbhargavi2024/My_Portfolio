About Ledgerline

Ledgerline is a portfolio project by Bhargavi Jakkampudi. It's a small operations console for a payments team: monitor volume, search and filter transactions, look at one transaction in detail, and work through a fraud-review queue.

It's based on the kind of screens I build for high-volume financial transaction platforms. All data here is generated in the browser. None of it is real.

UX decisions

  • The details panel keeps the user in context instead of sending them to a new page, so analysts don't lose their place in a filtered list.
  • Status uses color and a text label, and risk uses a bar count, so meaning never depends on color alone.
  • The table is keyboard-friendly: Tab to a row, Enter to open, Esc to close. Sort state is exposed with aria-sort.
  • Active filters show up as removable chips, so it's always clear why a row is or isn't in the list.
  • Light and dark themes run on CSS custom properties, the same pattern I use for shared design-system tokens.

How it maps to production

This demo is plain HTML, CSS and JavaScript so it opens anywhere without a build. In production I'd build the same screens as Angular standalone components with Signals for state, ag-Grid for the table, Angular Material for the drawer and form controls, and an HttpClient service talking to Spring Boot REST APIs.
